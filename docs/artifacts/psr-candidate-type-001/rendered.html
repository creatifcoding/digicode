Artifact Library / PSR

Candidate Type 001

A dogfood packet for proving the artifact can be reviewed, rendered, manifested, revised, and later seeded without smuggling server promises into source prose.

001 DOGFOOD
The packet is the boundary.

Claim ledger

Observed

OBSERVED: The packet includes Markdown, manifests, revisions, rendered HTML, and a dry-run seed script reference.

Proposed

PROPOSED: A future artifact-store CLI should ingest the bundle atomically and emit a durable receipt.

Blocked

BLOCKED: Live ingestion is not asserted because the Rust server/store implementation was intentionally not modified.

Local dry-run

./scripts/seed_psr_artifact.sh --dry-run
./scripts/seed_psr_artifact.sh --store ./var/artifact-store --dry-run

The script validates required files and JSON, then prints the proposed artifact-store seed command. Without --dry-run, it fails closed if the future CLI is absent.

Docker-minded dry-run

docker run --rm \
  -v "$PWD:/workspace" \
  -w /workspace \
  artifact-store:proposed \
  ./scripts/seed_psr_artifact.sh \
    --store /workspace/var/artifact-store \
    --dry-run

PROPOSED: The image name is a placeholder. BLOCKED: Publishing or building it is outside this packet.

Acceptance

  • PSR source is readable without a service.
  • Both manifests parse as JSON.
  • HTML rendering is standalone.
  • Revision annotation names what changed.
  • Server/store execution remains explicitly blocked until implementation exists.
