# Upstream provenance

This crate began from the MIT-licensed Linux computer-use backend in
[`ilysenko/codex-desktop-linux`](https://github.com/ilysenko/codex-desktop-linux),
subdirectory `computer-use-linux`.

The source was imported into Jcode on 2026-07-29 so Jcode owns, builds, audits,
and evolves the backend without a runtime dependency on an external checkout or
binary. The original MIT license is retained in `LICENSE-MIT`.

Jcode-specific integration and subsequent changes are tracked in this repository.
